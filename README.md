# shamefile-showcase

Real-world [`shamefile.yaml`](https://github.com/BKDDFS/shamefile)
examples generated from popular open-source projects.

Each entry shows shamefile running on a real codebase in a supported
language — suppression tokens found, documented with a written `why`,
and validated by `shame me . --dry-run`.

## How it works

Each entry lives under `<language>/<project>/` and contains:

- `shamefile.yaml` — the registry generated by running `shame me .`
  on the upstream project at a pinned commit SHA, with every `why`
  field filled in.
- `README.md` — upstream URL, commit SHA, suppression count, and a
  link back to the shamefile issue that tracks this language.

No source code is stored here. Clone the upstream project at the
recorded SHA if you want to browse the code in context.
